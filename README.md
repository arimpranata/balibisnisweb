# balibisnisweb

Tools for **Lightandpulse Digital Agency**, a Bali web studio building WordPress, Elementor and WooCommerce sites.

| Folder | What it is | Install |
|---|---|---|
| [`wordpress/lightandpulse/`](wordpress/lightandpulse/) | **WordPress theme** (Elementor-ready) with the Leads CRM built into wp-admin and a website lead form (shortcode + Elementor widget). | Zip the folder, then Appearance → Themes → Upload Theme. See its [`readme.txt`](wordpress/lightandpulse/readme.txt). |
| [`leads/`](leads/) | Standalone PHP version of the Leads app (no WordPress needed). | Upload to any PHP hosting. See [`leads/README.md`](leads/README.md). |

Both versions share the same features: free OpenStreetMap business search, website audits, a sales pipeline and WhatsApp/email outreach templates.
